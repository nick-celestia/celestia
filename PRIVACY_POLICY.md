This Privacy Policy explains what information Celestia collects, why it is collected, how it is used, and how users can request deletion.

Celestia is a Discord bot used for a virtual spirit-collection game. By using Celestia, you agree to this Privacy Policy and the Celestia Terms of Service.

## 1. Information Celestia collects

Celestia may collect and store the following information:

### Discord account and server identifiers

- Discord user ID
- Discord username/display name when needed for display or moderation context
- Discord server/guild ID
- Discord channel ID where required for server settings or logs
- Discord message ID only when needed for logs, support, abuse review, or future feature records

### Game data

- Mana balance
- Spirit inventory
- Spirit levels, XP, names, locks, and team setup
- Daily claim history and streaks
- Battle wins, losses, and streaks
- Item inventory and active item effects
- Summon count and collection progress
- Leaderboard data

### Premium or special feature data

If Celestia later supports paid or premium features, Celestia may store:

- STAR balance/status
- STAR submission status
- Custom spirit submission details
- Constellation Key access status and expiry
- Admin approval/rejection records

Celestia does not treat virtual items, Mana, STAR, or Keys as real money, cash, crypto, or transferable real-world value.

### Security and anti-abuse data

Celestia may store:

- Captcha/verification status
- Captcha trigger count
- Captcha failed attempts
- Ignored captcha command count
- Temporary or permanent bot-ban status
- Abuse/security logs
- Admin/helper actions
- Suspicious command timing patterns, if added later

### Command and support logs

Celestia may store logs for:

- Admin actions
- Economy changes
- STAR approvals/rejections
- Captcha/security events
- Large suspicious game events
- Bot errors
- Support and moderation review

Celestia does not intentionally store every normal chat message. Celestia reads command messages needed to operate the bot, such as messages starting with the configured prefix.

## 2. Why Celestia collects this data

Celestia uses this data to:

- Run the spirit collection game
- Save user progress
- Provide inventories, battles, daily rewards, shops, and leaderboards
- Prevent cheating, spam, scripts, and abuse
- Support captcha and security checks
- Review STAR/custom spirit submissions
- Help staff provide support
- Protect the game economy
- Comply with Discord requirements and applicable law

## 3. Data sharing

Celestia does not sell user data.

Celestia may share or process data through service providers needed to run the bot, such as:

- Discord, because Celestia operates through Discord
- Bot hosting providers
- Database providers such as MongoDB Atlas
- Captcha providers such as hCaptcha, if captcha is enabled
- Payment providers, if paid features are added later
- Legal or safety authorities when required by law

Staff access should be limited by role. Helpers should only access support/security information needed for their work.

## 4. Data retention

Celestia keeps game data while a user continues using the bot.

Security, admin, and economy logs may be retained longer to protect the bot from cheating, fraud, abuse, or economy manipulation.

Suggested default retention:

- Normal game profile data: until deletion is requested or the bot shuts down
- Captcha/security logs: up to 180 days, unless needed for ongoing abuse review
- Economy/admin/premium logs: longer when needed to protect the game economy or resolve disputes
- Error logs: as long as needed for debugging

These periods may be changed as Celestia grows.
