# QUICK REFERENCE — WHERE TO FIND EACH ID
# ═══════════════════════════════════════════════════════════════════════════════
#
# Discord User ID:
#   Enable Developer Mode → Discord Settings → Advanced → Developer Mode
#   Then: right-click any user → Copy User ID
#
# Discord Server (Guild) ID:
#   Right-click server name in sidebar → Copy Server ID
#
# Discord Channel ID:
#   Right-click channel name → Copy Channel ID
#
# Discord Role ID:
#   Server Settings → Roles → right-click role name → Copy Role ID
#
# Bot Token:
#   Discord Developer Portal (discord.com/developers/applications)
#   → Your application → Bot tab → Reset Token → Copy
#
# Bot Application ID:
#   Discord Developer Portal → Your application → General Information
#   → Application ID (copy the number)
#
# MongoDB URI:
#   MongoDB Atlas (cloud.mongodb.com) → Clusters → Connect
#   → Drivers → copy the connection string → replace <password>
#
# Railway domain:
#   railway.app → your project → your service → Settings → Networking
#   → Generate Domain (or use your custom domain)
#
# hCaptcha keys:
#   hcaptcha.com → sign in → Sites → New Site
#   → enter your Railway domain as hostname → save
#   → copy Site Key (public) and Secret Key (private)
#
# top.gg webhook:
#   top.gg → sign in → find your bot → Edit Bot → Webhooks
#   → URL: https://your-railway-domain.up.railway.app/topgg-webhook
#   → Authorization: paste your TOPGG_WEBHOOK_SECRET value
